# SHOPIQ n8n Automations
# -------------------------
# This directory holds n8n workflow exports (JSON) and webhook helpers
# for automated actions: WhatsApp orders, customer refill reminders,
# daily summaries, and dead-stock promotions.

# Reference: n8n runs at http://localhost:5678 (default n8n server).
# Django posts to these webhooks. n8n forwards to WhatsApp cloud API,
# email, or push notifications.

# To import a workflow: n8n UI -> Workflows -> Import from File.
